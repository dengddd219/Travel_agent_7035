# 广州｜老派约会之必要1⃣️

说点什么. . 6074 7046 149 发送 取消 广州｜老派约会之必要1⃣️ 这是一条非常好逛的city walk路线 感谢博主 @WangJY0513 的详细攻略。 我结合博主的路线，再穿插一些自己的探索，把美食融合进去，慢慢悠悠可以很好感受老广州的氛围～（地图在最后） 我把整个过程分成了两个部分，先从海珠广场地铁站到沙面岛，再从沙面岛到南信老铺。 沙面岛比较大，累了可以稍作休息，再继续出发。 具体路线：海珠广场——石室圣心大教堂——五代同糖糖水店——一德路石磨拉肠——粤海关——十三行博物馆——人民桥——沙面岛——露德圣母堂——南信牛奶甜品（如果想尝吴添记和陈财记的可以继续在南信导航，这两家店都在一条路上） 这周教堂因为复活节暂时不对外开放，在外面简单地转了一圈，不敢想象里面会有多漂亮！ 留一个遗憾，下次继续来～我带着珠江啤酒进了五代同糖糖水店，店员小姐姐给了我一个纸杯，慢慢喝着啤酒吃着西多士，幸福 一德路非常有生活气息。 冒烟的早餐店，穿梭的电机，还有背着书包上学的学生。 穿梭在狭窄逼仄的街道中我也体验了一把本地人的生活。 这家肠粉店是我随便尝试的，看到排队的人很多我也加入了。 果然好吃😋一德路外面是巨大的海产批发市场，内地的伙伴肯定和我一样觉得很新颖，看到了各种各样的海产。 然后就逛到了粤海关和十三行博物馆，博物馆里好多藏品都是王恒和冯杰伉俪捐赠的，太厉害了！ 一路上都没啥遮荫处，如果晴天出行一定要做好防晒哦～ 沙面岛好漂亮，色彩鲜艳的地方就会让人觉得心情愉悦。 圣母堂里的大姐很善良，热情地邀请我们进堂休息。 住在沙面岛的人应该也不会有烦恼吧！ 从沙面岛出来往南信方向走，一路上也可以看到很多老楼，老旧的建筑会让人感到安心，时代没有抛弃我们，我们倒退着走向未来。 总而言之这是一条适合放慢脚步感受广州生活的walk路线，祝愿大家广州之行愉快 #广州 #发现好地方 #探索城市隐秘角落 #沙面岛 #十三行 #旅行 编辑于 2025-04-23 哈哈哈哈哈 对不起见笑了 外地人私自给老字号改头换面了 我靠！ 五一去旅行正愁没有什么计划呢 而且我还正好有理光相机！ ！
