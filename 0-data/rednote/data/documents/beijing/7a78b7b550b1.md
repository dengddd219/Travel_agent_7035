# 在北京进行「老派約會之必要」

说点什么. . 3878 1924 93 发送 取消 在北京进行「老派約會之必要」 散步是进入与了解一座城市最好的方式，而北京这座城市是如此适合漫游。 我曾无数次幻想与你在北京进行一场「老派约会之必要」，加缪写过，“人们与一个城市分享的爱往往是秘密的爱。 ”我想边散步边跟你叙述我在这座城市的故事，其实是想带你走进我的过往人生回忆，也是对你秘密的爱。 春日我们一起去公园散步，地坛公园那面墙在阳光与树影的作用下像波光粼粼的海面。 夏天我们沿着鼓楼东大街一直走，去什刹海看落日消逝在地平线的那一端。 秋天我们去南锣鼓巷看金黄色的落叶掉下来，坐在有漂亮露台的咖啡馆喝咖啡。 冬天我们钻进路旁的涮肉店吃热气腾腾的铜锅涮肉，或走去胡同深处的铃木食堂吃上一顿寿喜烧。 然后我们挑一个午后一起去东四散步好吗？ 穿梭在胡同里，抬头可以看见满是翠绿叶子的树枝，枝桠是北京蓝天的脉络。 我想带你去以往我常逛的书店。 想同你说三联韬奋书店的窗边经常能看见七八十岁的爷爷奶奶在读书；可能有书旁边有一家好吃的包子铺；纸上声音书店能买到很便宜的纸质书，楼上的咖啡店有两只可爱的小猫，一本书与一杯咖啡通常就能坐一下午。 傍晚我们一起走在北京的蓝调时刻里，昏黄的路灯一路亮起，掩盖在春天的树叶里，是独属于北京的氛围。 然后一起去中国电影资料馆看一部老电影，去看《爱在黄昏日落时》怎么样？ 爱在系列三部曲我最喜欢的就是第二部，看完电影恋恋不舍地目送对方离开。 除了最近空气中飘荡着的柳絮有点不好。 但与你聊起柳絮时，你说柳絮其实是春天的使者，它们随着风飘荡在这座城市，观察这座城市来来往往行色匆匆的人们。 听到这里突然我感慨说：“我们终将成为北京这座城市的过客。 ” - 四月，有天坐地铁刷到了快手的文案大赛，其中有一条文案续写是：“你要写春天，别忘了写人间的暖。 老茶客在檐下，煮开一壶明前绿，母亲拆掉厚重的门帘，阳光跌进堂屋。 ” 读到这一段脑海里都是北京的四合院模样。 走在北京四月的街头，天气好时可以看见蓝天与抽出新芽的树木，路过公园能看见漂亮的不知名的小花儿，胡同树影斑驳，给人一种包容万象的感觉。 北京太大了，我们怎么逛
