# 春节成都三日游（已出行版

说点什么. . 1377 1502 12 发送 取消 春节成都三日游（已出行版 西安<->成都，出行方式高铁，西安北到成都东往返，成都东打车到市区很方便，成都打车超级便宜。 🥳涉及游玩地点：人民公园 -> 天府广场 -> 杜甫草堂 -> 武侯祠+锦里 -> 都江堰 -> 春熙路、太古里 -> 大熊猫基地（附图我出行的地点划分） DAY1： 人民公园 -> 天府广场 -> 杜甫草堂 -> 武侯祠+锦里 出行方式：地铁2号线+打车 住宿：汉庭优佳（成都一品天下蜀汉路），在2号线上，第二天也延住了（💰300多米） 吃饭：晚上在酒店附近吃了天星正源火锅，味道不错 人民公园：可以体验到本地居民的生活和松弛感觉，看到了著名的相亲角。 对面是宽窄巷子，晚上要去锦里，就放弃这个景点了，不是很喜欢美食街。 天府广场：大大的喷泉，买了泡泡玩。 挨着成都博物馆，没约到就没去。 杜甫草堂：就算是冬天也是柳绿花红的植被，旁边有一个浣花溪公园，可以散步。 武侯祠+锦里：过年期间有大庙会，下午有特色节目，晚上灯会亮起来特别好看。 锦里就是各地都有的美食购物街了. .
