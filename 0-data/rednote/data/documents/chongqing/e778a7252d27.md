# 重庆市区游玩

说点什么. . 2792 2461 33 发送 取消 重庆市区游玩 🏨重庆天绘酒店-观音桥红旗河沟地铁站店 因为出行基本就是地铁，所以选离地铁站口近的，尽量一直住在一家，少折腾。 作为山城，好多上下坡的路，真的费脚。 Day1 🍜到重庆后第一顿，重庆小面（对于不太能吃辣的我有点辣）、豌杂面（豌豆软糯，能抵消肉酱的辣），牛肉面（中规中矩，有辣椒的汤底算是特色吧） 解放碑🌇（P3） 🧋茶颜悦色，第一次喝到（幽兰拿铁等基本款都可点），茶味重的奶茶+鲜咸奶油+果干/巧克力等点缀，很多家店随走随买。 来福士-洪崖洞-千厮门大桥-大剧院江滩（可看到洪崖洞）(P4-P5)📸 这应该是最出片的地方了，只要看着桥挺大，对面洪崖洞是全景就可冲，晚上可以拍虚化背景人物照（调了很久相机，没拍出来想要的效果）。 因为到那里太晚，没有走到可以坐下来边喝饮料边看江景的区域。 Day2 🥘睡到9点，10点去附近居民区火锅店觅食。 (在此之后，得到结论，开在居民区的店是真的好吃便宜，后来去烟台和深圳也是这样） 山城步道(P6-P7) 俯瞰山城好地儿，大桥，居民区尽收眼底。 可以远眺长江国际（重庆18楼女孩必打卡-TFBOYS、时代少年团等的公司） (P8-P9)十八梯-长江索道→东水门大桥→下浩里老街（晚上可找驻唱清吧坐坐）→龙门浩老街（可看到东水门大桥 轻轨）→ 龙门浩月桥洞→过福门→走大桥→桥下滩石看夕阳（📸） 和好朋友一起出行，我们在在长江和岷江交汇的地方走下去，在江边散步，聊天，天气有点灰，没看到夕阳江对面是密密的高层，很明显是建在山上，看起来就是国家投了不少钱建起来的样子。 Day3 红色旅游线路，买个大巴通票 渣滓洞 长篇小说《红岩》取材于此 白公馆 小萝卜头 磁器口 人造古镇，主要在里边买了些特产，陈昌银酥脆小麻花，重庆怪味胡豆，可以买完直接邮寄，不过淘宝上也都有，也不贵，看自己需求尝尝鲜购买就好啦。 观音桥小吃街P10 很商业化的小吃商场，里边的东西和各地小吃集合地都很相似，是真的很大很全，外景拍照比较好看。 Day4(P11-P13)📸 三峡博物馆 重庆市人民大礼堂 在三峡博物馆台阶上
