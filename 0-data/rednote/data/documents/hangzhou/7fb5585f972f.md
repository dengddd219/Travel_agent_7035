# 来杭州一定要走一次的徒步路线，满眼绿意！

说点什么. . 3112 2751 262 发送 取消 来杭州一定要走一次的徒步路线，满眼绿意！ 如果春天只能来杭州走一条徒步路线 我一定会选九溪到龙井村 全程平缓不累，溪水潺潺、茶园连绵 不用挤人潮，就能独享江南春日的静谧与清新 - 🚇交通：地铁至水澄桥站，转公交直达九溪入口 - 🏃🏻路线规划（全程4-5km，慢行3-4h） 九溪入口→九溪十八涧→九溪烟树→龙井村→十里琅珰 整条路线依山傍水，全程石板路，几乎无陡坡，边走边逛完全不费腿，春日出行舒适度拉满 - ✅九溪烟树 碧绿的湖水清澈见底，四周绿树环绕，不管什么时候来，都有不一样的美感，非常适合驻足打卡 ✅九溪十八涧 蜿蜒的石板路穿梭在林间，溪水顺着山势缓缓流淌，一路绕着青山、伴着流水，随手拍都是森系大片 ✅龙井村 一进村就被万亩茶园包围，空气里都弥漫着淡淡的茶香，白墙黑瓦的古村落坐落在茶山之间，感受浓浓的茶乡气息，也能找一家茶馆坐下，品一杯正宗的龙井茶，享受慢时光 ✅十里琅珰 想要俯瞰整片茶园风光，一定要登十里琅珰，沿着龙井村的茶山步道向上走，连绵成片的茶山尽收眼底，既能看到山间云雾，又能俯瞰村落美景，吸氧又治愈 - 这条路线是妥妥的天然氧吧，不用赶时间，走走停停、拍照休憩，既能感受大自然的美好，又能放松身心，不管是独自散心、情侣出游，还是闺蜜拍照、家庭遛娃都很合适 - 徒步逛累了，当然要用甜甜的糕点补充能量，来杭州必买的南宋胡记，和这条茶香徒步路线适配度拉满！ ✔️龙井花挞 挞皮烤得金黄酥脆，茶香清爽淡雅，甜而不齁，一口下去，带着淡淡的龙井回甘 ✔️杏花酥 掰开就能闻到淡淡的杏花香，吃起来清香爽口，不管是徒步中途垫肚子，还是拍照当道具，都仙气十足 ✔️龙井味黄油年糕 融入了正宗龙井茶香，酥皮层层起酥，茶香醇厚不腻，黄油香气浓郁，吃完满口留香 ✔️太子湾同款郁金香酥 外皮软糯绵密，内馅清甜可口，花香与果香交织，口感层次丰富 ✔️雪顶梅花泡芙 外皮酥软，内里塞满绵密的奶油，雪顶清甜不腻，徒步过后吃上一个，瞬间赶走疲惫 不管是徒步途中解馋，还是返程当做伴手礼带回家都很合适，把杭州的春日美好和香甜滋味一起珍藏 #南宋龙井
