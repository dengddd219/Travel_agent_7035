# 为啥网上都说厦门不好玩（附一个自己的攻略）

说点什么. . 2420 1793 58 发送 取消 为啥网上都说厦门不好玩（附一个自己的攻略） 我们属于比较随意比较懒的游客，没去每一个景点打卡，但是总体来说去厦门没被坑，本来想按照博主王西北（见p4）的攻略玩的，但是我和对象实在是起不来。 1️⃣第一天 🌴鼓浪屿：没买到票，可以候补，而且比较快。 网上都说鼓浪屿不值当，但是我们全程避开商业街走，我个人觉得它那的植物，建筑，海景都很美，我很喜欢。 最后走到了美华沙滩在那玩了很久的沙子，港仔沙滩很多人。 🐷🥘朱富贵：晚上去吃了朱富贵，是那种海鲜半自助火锅，非常划算，扫码加个微信群还能打68折，吃了一大桌才170多。 不推荐海参，很腥，其他都不腥，锅底味道比较淡。 2️⃣第二天 厦门植物园：🌳热带雨林区有很多摄影师很会拍，基本上都是二十一张，一百六张也还好，主要是太出片了，人很多。 🌵多肉区超级壮观，也很出片。 千万别买便宜的网红爆款裙子去，我那个绿裙子👗在小小植物园居然撞衫至少五个人哈哈哈 🏞️黄厝沙滩：下午去的，拍了一些照片，那边有沙滩椅，买点酒水喝就可以坐，很巴适。 🦪阿伟生蚝馆：他家生蚝很好吃，七块一个，你可以先吃一个尝尝，其他的海鲜烧烤都还行，味道偏淡。 避雷那个蘑菇虾，就是皮皮虾，味道还行，但是超级难剥，还没啥肉。 3️⃣第三天 本来准备去高崎机场拍飞机✈️的，然后去集美学村，但是那天下雨🌧️就返回了，途中吃了本地人评论区推荐的邹公家的沙茶面🍜，淡淡的沙茶味道，我和对象都觉得好吃能接受૮₍ᵔ⤙ᵔ ₎ა。 白城沙滩🏖️：那边离厦大近，有人在那布置场景拍照，喜欢的也可以拍一张。 晚上还是吃的阿伟生蚝馆，试了一下石斑鱼🐟和海蛎煎🐚都还不错。 🏨住的是文灶地铁站的汉庭，周围很多吃的（阿伟，万惠香扁食，蜜雪什么的都在附近），楼下就有一个折扣超市，买水和酒超便宜，对面也有一个便宜的零食店。 坐地铁也方便，但是我们出行都是打车，厦门地铁线路比较少。 网上都不推荐住民宿，不干净。 最后真的很喜欢厦门的绿化，太美了，有机会再去第二次。 #去过一次还想再去的城市 #旅游 #厦门 #厦门旅游 #厦门美食 #厦门攻略 #鼓浪屿 #厦门
