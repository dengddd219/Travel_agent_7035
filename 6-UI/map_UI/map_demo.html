Amap UI Demo

独立可运行的高德地图组件

这页用于地图同学本地自测。地图逻辑只依赖 window.renderTravelMap(mapPayload)，不依赖后端、不依赖总 UI 页面。

路线预览方式，仅影响地图画线，不修改后端行程时间、距离和预算。

联调说明

总 UI 联调时调用后，直接把返回的 data.map_payload 传给组件。
组件本身不关心 conversation state，只消费最新的 map_payload。

使用前请确认：

  • 这是高德前端 JS API Key，不是后端 Web 服务 Key。
  • 如果你把 key 配在同级目录的 ../azure_client/.env，请用 python serve_demo.py 启动。
  • 坐标按文档默认视为 GCJ-02，无需前端转换。
  • 如果真实接口返回坐标为 0 或 null，组件会自动跳过不渲染。
