## 步骤3：路线聚类和跨区硬约束

### 文件
`3-travel_planner/travel_planner/planner.py`

### 现状

- `_allocate_days()`（第504行）：主区候选耗尽时走 backup，backup 过滤条件是 `candidate.district in chosen_districts`（已选区）或 `len(chosen_districts) < 2`（区数不足2才允许新区）。
- `_related_to_chosen()`（第367行）：bool 返回，满足 cooccurrence 或 distance≤8km 即通过。
- **问题**：没有"第3个区必须同时满足 distance≤5km AND route_pair 关系"这个硬门槛；`route_pair_hints` 也没有驱动主区内的 POI 排序（只是 bool 判断是否放行 backup）。

### 目标行为

1. **每天最多 3 个区**（含 main_district）。第3个区候选需同时满足：
   - 与当天已选任意 POI distance ≤ 5km，**且**
   - 在 `cooccurrence_map` 中与当天已选任意 POI 有共现关系。
   - must_visit 豁免此限制。

2. **route_pair_hints 驱动 main_district 内 POI 排序**：在 `district_candidates.sort()` 之前，对候选 POI 按 cooccurrence 关系打额外加分（cooccurrence_boost），使攻略明确连线的点排在靠前位置。

### 具体修改

#### A. 常量（第34行附近）

#### B. `_related_to_chosen()`（第367行）改为返回 `(bool, float)`

```python
def _related_to_chosen(
    poi: POI,
    chosen_pois: list[POI],
    strategy_signals: dict,
) -> tuple[bool, float]:
    """
    返回 (is_related, km_to_nearest_chosen)。
    is_related=True 表示满足 cooccurrence 或 distance≤NEARBY_CLUSTER_KM。
    km_to_nearest_chosen 供调用方做第3区距离门槛判断。
    """
    cooccurrence = strategy_signals.get("cooccurrence_map", {})
    poi_key = poi.name.lower()
    nearest_km = float("inf")
    has_cooccurrence = False

    for chosen in chosen_pois:
        chosen_key = chosen.name.lower()
        if poi_key in cooccurrence.get(chosen_key, set()) or chosen_key in cooccurrence.get(poi_key, set()):
            has_cooccurrence = True
        distance = _haversine_km(poi.lat, poi.lon, chosen.lat, chosen.lon)
        if distance is not None:
            nearest_km = min(nearest_km, distance)

    is_related = has_cooccurrence or nearest_km <= NEARBY_CLUSTER_KM
    return is_related, nearest_km
```

> 注意：`_haversine_km` 已存在（第342行），直接复用。

#### C. `_allocate_days()` backup 过滤（第600-622行）

将原来的 backup 过滤块替换为：

```python
chosen_districts = {poi.district for poi in chosen_pois if poi.district}
chosen_districts.add(main_district)

filtered_backup = []
for candidate in backup:
    is_must = _is_must_visit_poi(candidate, must_visit)
    support_only = _is_support_only_poi(candidate, strategy_signals, preferences)

    # must_visit 无条件放行
    if is_must:
        filtered_backup.append(candidate)
        continue

    # 辅助点上限
    if support_only and support_count >= MAX_SUPPORT_STOPS_PER_DAY:
        continue

    # 候选在已选区内：直接放行
    if candidate.district in chosen_districts:
        filtered_backup.append(candidate)
        continue

    # 候选在新区：需满足跨区约束
    new_district_count = len(chosen_districts) + (0 if candidate.district in chosen_districts else 1)
    if new_district_count > MAX_DISTRICTS_PER_DAY:
        continue  # 已达上限，拒绝

    is_related, nearest_km = _related_to_chosen(candidate, chosen_pois, strategy_signals)
    if not is_related:
        continue  # 无关联，拒绝

    # 第3区（new_district_count == MAX_DISTRICTS_PER_DAY）需同时满足距离+共现
    if new_district_count == MAX_DISTRICTS_PER_DAY:
        cooccurrence = strategy_signals.get("cooccurrence_map", {})
        poi_key = candidate.name.lower()
        has_cooccurrence = any(
            poi_key in cooccurrence.get(chosen.name.lower(), set())
            or chosen.name.lower() in cooccurrence.get(poi_key, set())
            for chosen in chosen_pois
        )
        if nearest_km > THIRD_DISTRICT_MAX_KM or not has_cooccurrence:
            continue  # 第3区门槛不满足

    filtered_backup.append(candidate)
```

新增函数 `_apply_content_type_quota()`：

```python
def _apply_content_type_quota(
    results: list[dict],
    min_route_plan: int = 2,
    min_pitfall: int = 1,
) -> list[dict]:
    """
    确保 results 里 content_type=route_plan 至少 min_route_plan 条、
    pitfall/avoid_guide 至少 min_pitfall 条。
    如果已满足，原样返回；否则把不足类别的条目提前。
    不增加 results 总数，只调整顺序（稳定排序）。
    """
    PITFALL_TYPES = {"pitfall", "avoid_guide"}
    ROUTE_TYPES = {"route_plan", "attraction_guide", "hidden_gem", "family_route"}

    route_items = [r for r in results if str(r.get("metadata", {}).get("content_type", "")).lower() in ROUTE_TYPES]
    pitfall_items = [r for r in results if str(r.get("metadata", {}).get("content_type", "")).lower() in PITFALL_TYPES]
    other_items = [r for r in results if r not in route_items and r not in pitfall_items]

    # 按配额拼接：先保证 route，再保证 pitfall，再放其余
    ordered = route_items[:min_route_plan] + pitfall_items[:min_pitfall]
    seen_ids = {id(r) for r in ordered}
    for r in route_items[min_route_plan:] + pitfall_items[min_pitfall:] + other_items:
        if id(r) not in seen_ids:
            ordered.append(r)
            seen_ids.add(id(r))

    return ordered
```

**调用位置**（在 `final_results` 赋值后、进入 `_build_evidence_layer` 前）：

```python

```
