## `1-rag_pipeline_delivery/` — RAG 离线摄取管道

**改动：未直接修改 Group A 的 Python 文件。**

我们与 Group A 协商了接口契约，推动他们在 chunk metadata 中增加了 B 组所需字段。协商过程和字段要求记录在：

```
1-rag_pipeline_delivery/a_group_rag_api_contract.md
```

### 我们要求 Group A 在 metadata 中包含的关键字段

Group A 的 `rag/chunking/splitter.py` → `_make_chunk()` 函数负责组装每个 chunk 的 metadata。
我们协商后，他们的 metadata 包含了以下字段（`splitter.py:190-210` 附近）：

```python
"metadata": {
    "source_id": ...,
    "city": ...,
    "content_type": ...,   # 我们要求的：区分 attraction_guide / food_guide / pitfall_warning 等
    "tags": [...],         # 我们要求的：list[str]，供兴趣匹配
    "poi_names": [...],    # 我们要求的：list[str]，供地图工具标准化坐标
    "districts": [...],    # 我们要求的：list[str]，供区域聚类
    "travel_type_tags": [...],  # 我们要求的
    "time_suggestions": [...],
    "poi_types": [...],
    "chunk_index": ...,
}
```

### ChromaDB 的 metadata 序列化问题

Group A 的 `rag/storage/chroma_store.py` 把 list 字段存成了逗号分隔字符串（ChromaDB 不支持 list 类型）。
我们在 `2-rag-retrival/search_notes.py` 的 `_restore_metadata()` 函数中做了反序列化还原：

```python
# search_notes.py: _restore_metadata()
list_fields = {"tags", "poi_names", "districts", "travel_type_tags",
               "time_suggestions", "poi_types"}
for k, v in raw.items():
    if k in list_fields:
        if isinstance(v, str):
            restored[k] = [x.strip() for x in v.split(",") if x.strip()] if v else []
```

**如果 Group A 之后修改了 chroma_store.py 的存储方式（比如改用 JSON 序列化），`_restore_metadata()` 需要同步更新。**

### BM25 pkl 格式约定

Group A 的 `rag/storage/bm25_store.py` 生成的 `bm25_index.pkl` 需要包含以下 key，我们的 `_load_bm25()` 依赖这些 key：

```python
{
    "chunk_ids": list[str],
    "chunk_texts": list[str],
    "tokenized_corpus": list[list[str]],  # 分词后的语料，直接复用避免重新分词
}
```

**如果 Group A 修改了 pkl 的 key 名称或结构，`search_notes.py` 的 `_load_bm25()` 函数需要同步更新。**

## `2-rag-retrival/` — 在线检索 API（我们写的对接层）

**整个文件夹由我们编写，不是 Group A 的代码。**

`search_notes.py` 是我们写的桥接层，作用是把 Group A 交付的 ChromaDB + BM25 封装成一个干净的函数接口供 B 组 Agent 调用。

### 关键设计决策

**1. 路径硬编码指向 Group A 的交付物**

```python
# search_notes.py: 顶部
_RAG_ROOT = Path(__file__).resolve().parents[1] / "1-rag_pipeline_delivery"
_BM25_PKL = _RAG_ROOT / "data" / "db" / "bm25" / "bm25_index.pkl"
_CHROMA_DIR = _RAG_ROOT / "data" / "db" / "chroma"
```

如果 Group A 修改了数据库输出路径，这里需要同步更新。

**2. sys.path 注入 Group A 的 rag 包**

```python
if str(_RAG_ROOT) not in sys.path:
    sys.path.insert(0, str(_RAG_ROOT))
```

这样可以 `from rag.embedding.embedder import get_embeddings` 直接复用 Group A 的 embedder，保证向量检索和摄取时用同一个模型。

**如果 Group A 重命名了 `rag/` 包或移动了 embedder 路径，这里会 ImportError。**

**3. hybrid 策略的 RRF 权重**

```python
# _rrf_fuse(): dense_weight=0.6, bm25_weight=0.4
```

这个权重是我们根据 Group A 的 `evaluate.py` 评估结果（HR=84%, MRR=1.00）设定的。如果 Group A 重跑评估后建议调整权重，在 `_rrf_fuse()` 调用处修改即可。

**4. BM25 的城市过滤降级逻辑**

BM25 pkl 不含 metadata，我们用 chunk_text 首 50 字符包含城市名来粗过滤：

```python
# _bm25_city_filter()
if city in ct[:50]:  # 标题行通常包含城市名
```

如果过滤后结果 < 10 条，自动回退全量。这是一个脆弱点——如果 Group A 修改了 chunk 的标题前缀格式（`【标题】\n正文`），这个逻辑可能失效。

### 公开 API 签名（供 B 组 Agent 调用）

```python
def search_notes(
    query: str,
    city: str = "",
    category: str = "",
    strategy: str = "hybrid",   # "dense" | "hybrid" | "filter"
    top_k: int = 5,
) -> list[dict]:
    ...
```

返回结构每条固定为：
```python
{
    "chunk_id": str,
    "score": float,
    "chunk_text": str,
    "metadata": {
        "source_id": str, "city": str, "content_type": str,
        "tags": list[str], "poi_names": list[str], "districts": list[str],
        "title": str, "source_platform": str, "travel_type_tags": list[str],
        "time_suggestions": list[str], "poi_types": list[str], "chunk_index": int,
    }
}
```

B 组的 `3-travel_planner/travel_planner/tools/strategy_rag_adapter.py` 通过 `importlib` 动态 import 这个函数。

### Group C 返回值的已知特殊处理

**weather_adapter.py 中的补丁：**

Group C 的天气返回不一定包含 `precipitation_probability` 字段。我们在 `weather_adapter.py` 中从 `condition` 文本推断：

```python
# 如果没有 precipitation_probability，从天气描述文本推断
if "precipitation_probability" not in day:
    condition = day.get("condition", "")
    if any(w in condition for w in ["雨", "雪", "阵雨"]):
        day["precipitation_probability"] = 0.7
    elif "云" in condition:
        day["precipitation_probability"] = 0.2
    else:
        day["precipitation_probability"] = 0.05
```

**cost_adapter.py 中的补丁：**

Group C 的费用返回中，价格区间是字符串格式 `"200-300"`，我们做了解析：

```python
# 解析 "200-300" → (200, 300)
parts = range_str.split("-")
low, high = float(parts[0]), float(parts[1])
```
